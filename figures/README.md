# Figure Directory Layout

Figures are organized by model family/scale. Each model folder keeps the same
three artifact types:

- `pdf/`: paper-ready figures for LaTeX.
- `csv/`: plotted data and missing-data audits.

Current model folders:

- `llama8b/`: main-paper Llama-8B figures and fine-grained analyses.
- `qwen/`: Qwen companion figures.
- `llama70b/`: Llama-70B companion figures.

Fine-grained Llama-8B analyses are under `llama8b/finegrained/`, split into
`one_axis/` and `multi_axis/`.
